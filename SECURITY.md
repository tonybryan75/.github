# Security Policy

## Reporting a vulnerability

Please report security issues **privately** rather than opening a public issue.

- Preferred: open a [GitHub private security advisory](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
  on the affected repository.
- Or email **tony.n.bryan@gmail.com** with details and reproduction steps.

I'll acknowledge receipt and work with you on a fix and disclosure timeline. Thanks for helping
keep these projects safe.
