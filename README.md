# .github

This is the GitHub **special repository** for [@tonybryan75](https://github.com/tonybryan75). It
holds the profile page and the default community-health files — issue/PR templates, contributing,
security, and code-of-conduct — that apply to repositories without their own.

- **Profile page:** [`profile/README.md`](./profile/README.md) — rendered at
  [github.com/tonybryan75](https://github.com/tonybryan75).
- **Default review config:** [`.coderabbit.yaml`](./.coderabbit.yaml) — the org-wide CodeRabbit
  defaults, applied to repos that don't override them.
